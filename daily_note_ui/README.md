# Daily Note UI (`daily_note_ui`)

A feature-rich React component for creating, categorizing, and managing comprehensive daily notes, tasks, and meeting logs. Built with React and standard Bootstrap styling.

---

## 🌟 Key Features

* **Rich Note Metadata**: Title, Priority badges (Low/Medium/High), Categories, Status tracking, Project/Board links, Version tags, and Access Visibility controls.
* **Custom Scheduling & Reminders**: Native `datetime-local` selectors for Created Date/Time, Due Date/Time, and customizable alert scheduling.
* **Actionable Checklist**: Interactive, embedded to-do list with item completion toggles and removal.
* **File Attachment Support**: Multi-file upload interface with live preview lists and size badges.
* **Personalization & Toggles**: Custom theme color presets, Confidentiality locks, Pinned notes toggle, and Automated Recurrence rules.
* **Clean & Responsive Layout**: Form layout structured with Bootstrap grid classes.

---

## 🛠️ Tech Stack

* **Frontend**: React (Hooks-based functional components)
* **Styling**: Bootstrap 5
* **Build Tool**: Vite / Create React App
